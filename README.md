# Snowbound Kingdom Quests

SNOWQUEST — COMPLETE FRONTEND VISUAL DESIGN MASTER PROMPT
Make it on a snow winter theme.

PROJECT OBJECTIVE
Create a premium, visually stunning Telegram Mini App frontend named SnowQuest.
I have provided a reference image showing five mobile app screens. Treat this image as the primary visual design reference.
Your task is to recreate its visual language, artwork style, colors, decorative elements, icons, card designs, typography, borders, spacing and overall premium appearance as closely as possible.
The application must contain exactly five tabs:
Home
Tasks
Games
Events
Account

The final result should look like a professionally designed premium fantasy winter gaming application.
